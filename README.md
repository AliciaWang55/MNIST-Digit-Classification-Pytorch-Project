MNIST Digit Classifier with Interactive Drawing Interface

A convolutional neural network (CNN) built in PyTorch that recognizes handwritten digits (0-9). Train it on the MNIST dataset, then draw your own digit in a window and watch the model predict it in real time, with a bar chart showing the probability for every digit.

Test accuracy: 98.90% (9,890 / 10,000 MNIST test images) after only 3 epochs of training.
